# Ghormeh Sabzi recept

Det här är en enkel receptsida för Ghormeh Sabzi. Layouten är gjord efter en Figma-design, men innehållet och bilderna är anpassade till mitt eget recept.

## Filer

- `index.html` innehåller sidans struktur och text.
- `style.css` innehåller designen, till exempel färger, avstånd och bildstorlekar.
- `images/` innehåller bilderna som används på sidan.

## Så öppnar man sidan

Öppna `index.html` i webbläsaren.
